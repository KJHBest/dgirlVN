# 분기 & 플래그 설계

## 1. 변수 목록

### 회차 변수 (새 게임 시 초기화)

| 변수 | 범위 | 의미 |
|---|---|---|
| `K_AFF` | 0~ | 크라노시아 호감. **공통 루트 분기 판정용** |
| `E_AFF` | 0~ | 에테르니아 호감. **공통 루트 분기 판정용** |
| `DOUBT` | 0~2 | 하바에 대한 의심. 크라노시아 루트 K-07의 대사량이 달라짐 (엔딩 영향 없음, 진실 루트 복선) |
| `K_SHARE` | -∞~ | **"짐을 나눈다"** — 크라노시아가 혼자 짊어지지 않게 했는가. 주인공이 자기희생을 고르면 감소 |
| `E_REAL` | 0~ | **"진짜 얼굴"** — 에테르니아가 성녀가 아닌 자신으로 있을 수 있게 했는가 |
| `E_SPY` | 0~ | **내통자 단서** — 비비안의 백도어를 얼마나 추적했는가 |
| `K_FLINCH` | flag | 프롤로그 시험에서 "내가 미끼가 된다"를 골랐다 (K-08에서 회수) |
| `E_NOTICE` | flag | 첫 만남에서 그녀의 피로를 알아챘다 (E-03 도입부가 바뀜) |
| `K_MORGANA` | flag | K-02에서 모르가나 이야기를 들었다 (K-06 대사 추가) |
| `VIVIAN_EXPOSED` | flag | E-07에서 비비안을 추궁해 동요시켰다 |
| `KITTEN` | flag | C-06K에서 고양이 '사사'를 데려왔다 (크라노시아 루트 곳곳에 등장) |
| `K_ASKED_STOP` | flag | K-09에서 "멈춰줘"를 골랐다 (K-BAD 도입부 분기) |
| `E_DRAWING` | flag | C-06E에서 아이의 '진짜 하늘' 그림을 봤다 (E-HAPPY 연출 분기) |
| `E_PATCHED` | flag | E-06 종료 시 `E_SPY ≥ 2` → 글레이시아의 방화벽 패치 완성 |
| `E_CALLED_SAINT` / `E_RAISED_GUN` | flag | E-09 오답 선택 (E-BAD 도입부 분기) |

### 영구 변수 (회차를 넘어 유지 — "잔향")

| 변수 | 의미 |
|---|---|
| `ECHO` | 루프 리셋(데드엔드·배드엔딩)을 겪은 횟수 |
| `LOOP` | 표시용 회차 번호. 첫 플레이 = 1208, 리셋마다 +1 |
| `SEEN_DEAD0` `SEEN_DEAD1` `SEEN_DEAD_K1` `SEEN_DEAD_E1` | 데드엔드 확인 |
| `SEEN_K_BAD` `SEEN_K_HAPPY` `SEEN_E_BAD` `SEEN_E_HAPPY` | 엔딩 확인 |

> **설계 의도** : 배드엔딩이 "실패"가 아니라 **다음 회차의 무기**가 되게 한다. 주인공이 잔향을 느끼는 설정과 플레이어의 회차 플레이를 일치시키는 것이 이 작품의 핵심 메타 장치.

## 3. 잔향(ECHO) 연출 규칙

- **K-BAD는 예외** : 시간이 멈췄으므로 되감기가 일어나지 않는다. `ECHO+1`만 하고 `LOOP`는 올리지 않는다. 타이틀에 `LOOP 1208 ─ 종료되지 않음` 표시.
- 루프 리셋 시 : 화면이 04:44에서 멈춘 시계 → 초침이 역회전 → 화이트아웃 → 프롤로그. 타이틀의 회차 표시 `LOOP 1208 → 1209`.
- 이미 읽은 문장 : 일반 VN의 '기독 표시' 색 대신 **글자가 아주 살짝 번져 보이는 효과**. 주인공의 잔향을 UI로 표현.
- ◆ 잔향 선택지 : 선택지 앞에 ◆, 글자색 청백색. 루프를 겪지 않으면 절대 보이지 않는다.
- **교차 루트 카메오** (엔딩 영향 없음, 보상 연출)
  - `SEEN_E_HAPPY` 상태로 크라노시아 루트 K-06 → 에테르니아가 원거리 지원 사격으로 등장
  - `SEEN_K_HAPPY` 상태로 에테르니아 루트 E-09 → 크라노시아가 비비안을 먼저 제압해 둠
- 두 해피엔딩 모두 달성 → 타이틀 화면에 하바의 음성 한 줄 추가 + "진실 루트 — Coming Soon"

## 5. Unity 구현 메모

- **회차 변수** : Ink 전역 변수. 세이브 파일에 저장.
- **영구 변수** : Ink 외부(Unity 측) `PersistentData` — `PlayerPrefs` 또는 별도 JSON. 게임 시작 시 Ink에 바인딩(`ECHO`, `SEEN_*`)해서 조건문에서 읽기 전용으로 사용.
- 대본 태그(`@bg` `@show` `@cg` `@bgm` `@se`)는 Ink의 `# tag`로 변환 → Unity 쪽 `ScenePresenter`가 해석.
- 원작 `DialogueData`(character / sentences / choices / choiceResults) ScriptableObject는 **"한 번 선택하고 한 줄 반응"** 구조라 VN 분기에는 부족하다. 원작 데이터는 이미지·전투 에셋 재활용 용도로만 쓰고, 대사 데이터는 Ink로 새로 가는 것을 권장.
